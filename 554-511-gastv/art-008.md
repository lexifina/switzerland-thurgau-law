# § 8 Prüfungserlass
1 Personen, welche während mindestens drei Jahren einen Gastgewerbebetrieb geleitet haben oder einen Fähigkeitsausweis über eine abgeschlossene Berufslehre auf den Gebieten Nahrung oder Gastgewerbe besitzen und in diesem Bereich über eine mindestens dreijährige Berufserfahrung in leitender Funktion verfügen, wird die Prüfung erlassen, sofern sie für eine einwandfreie Betriebsführung Gewähr bieten.
2 Für einzelne Fachbereiche kann das Departement eine Ergänzungsprüfung verlangen.
